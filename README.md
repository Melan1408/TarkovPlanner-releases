# Tarkov Planner — релизы

Здесь лежат только собранные версии Tarkov Planner. Исходный код — в отдельном закрытом репозитории.

**Установка:** откройте [последний релиз](https://github.com/Melan1408/TarkovPlanner-releases/releases/latest),
скачайте `TarkovPlanner.exe`, положите в обычную папку (рабочий стол, «Документы» — не `Program Files`)
и запустите.

**Обновление:** лаунчер программы сам проверяет новую версию и обновляется кнопкой «Обновить до …».

`update.json` и `update.json.sig` в каждом релизе — описание версии для лаунчера и его подпись ключом разработчика:
без верной подписи программа обновление не ставит.
