# Tarkov Planner

Подсказывает, какие предметы в Escape from Tarkov **не продавать**: они понадобятся для будущих квестов
и модулей убежища. Работает на вашем компьютере, открывается в браузере.

Здесь лежат только собранные версии программы.

## Установка

1. Откройте **[последний релиз](https://github.com/Melan1408/TarkovPlanner-releases/releases/latest)** и в разделе
   **Assets** скачайте **`TarkovPlanner.exe`** (около 90 МБ).
   - Браузер может предупредить, что файл скачивают редко. В Chrome нажмите «Сохранить», в Edge — «…» →
     «Сохранить» → «Всё равно сохранить».
2. Положите `TarkovPlanner.exe` в обычную папку: на рабочий стол, в «Документы» или в свою.
   **Не в `Program Files`**: туда программа не сможет записать обновление.
3. Запустите двойным кликом.
   - Синее окно «Windows защитил ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае». Так бывает
     с программами без платной цифровой подписи; спросит один раз.
   - Окно брандмауэра: телефон не нужен — «Отмена»; нужен — «Разрешить доступ».
4. Откроется небольшое окно — **лаунчер**. Нажмите **«Открыть»**: программа откроется в браузере по адресу
   **http://127.0.0.1:5075** — добавьте его в закладки.
5. Создайте профиль: название вайпа, дата начала, фракция. Дальше отметьте, что уже выполнено, или загрузите прогресс
   из логов игры в «Настройках».

## Полезно знать

- **Крестик в лаунчере закрывает программу.** Чтобы она работала в фоне (следила за логами, отвечала на хоткей),
  лаунчер **сворачивайте** — он уйдёт к значку у часов (может прятаться под «^»). Вернуть лаунчер — двойной клик
  по значку. Закрыть вкладку браузера — не значит закрыть программу.
- **Обновления — сами:** лаунчер при открытии проверяет новую версию и показывает кнопку «Обновить до …».
  Прогресс сохраняется, перед обновлением делается его копия.
- Интернет нужен при первом запуске: список квестов и картинки (около 35 МБ, полминуты). Дальше работает и без него.
- Ваш прогресс хранится в `%LOCALAPPDATA%\TarkovPlanner`, а не в самом `.exe`. Чтобы перенести его на другой
  компьютер, закройте программу («Выход») и скопируйте эту папку.
- Можно открыть на телефоне в той же Wi-Fi сети: «Настройки» → «Доступ с телефона» → отсканировать QR-код.

## Если что-то не так

- **Браузер не открылся по «Открыть»** — откройте http://127.0.0.1:5075 вручную.
- **«Не удалось запустить сервер»** — адрес занят другой программой: закройте её или перезагрузите компьютер.
- **«Не удалось обновить: нет доступа к файлу приложения»** — перенесите `TarkovPlanner.exe` из `Program Files`
  в обычную папку и нажмите «Обновить» снова.

## Про файлы релиза

не нужно. Без верной подписи программа обновление не ставит.
